# Devflow Diff Explain

Личный инструмент, который проводит по PR от общей архитектуры к отдельным строкам кода: краткое описание проблемы и решения, схема потока данных с окружением изменения, смысловые блоки и упорядоченные файлы с полным диффом. Пояснения внутри файла выделяют важные места; детали можно спросить в чате с привязкой к строкам.

Целевой интерфейс — браузер на компьютере. Сервер хранит импортированные снимки и предоставляет чтение, объяснение и чат; не публикует комментарии и вердикты, не ведёт ревью-отметки и не запускает исправления кода. Сохранённые разборы доступны для чтения без подключённого агента.

## Установка и обновление

Нужны Node ≥ 22.13 и pnpm версии из `package.json`.

```sh
pnpm install --frozen-lockfile
pnpm install:local
```

Установщик собирает приложение и копирует пять проверенных файлов, включая метаданные вызова, в `~/.agents/skills/devflow-diff-explain`. Симлинки не используются. Предыдущая установка сохраняется вне каталога скиллов; путь резервной копии печатается в конце. Обновление выполняется той же командой после изменения исходников.

Для другого каталога скиллов:

```sh
node scripts/install-local.mjs --target /path/to/skills/devflow-diff-explain
```

## Использование

В списке скиллов выбери **«Дифф — объяснить»** или явно вызови его в чате агента. По содержанию задачи скилл автоматически не запускается.

Пример явного вызова:

```text
$devflow-diff-explain <ссылка на PR>
```

Агент сам читает PR или локальные изменения доступными ему инструментами и скиллами. Он экспортирует полный инвентарь изменений и точные байты обеих сторон файлов; приложение импортирует готовый снимок. Адаптеров Arcanum/GitHub/Arc/Git, авторизации провайдеров и автоматического опроса PR в приложении нет. Дополнительные источники, использованные в объяснении или ответе, агент импортирует перед публикацией.

Агент открывает локальный UI и строит объяснение. Начни с описания, затем прокручивай блоки и полные диффы файлов одной лентой в предложенном порядке. Содержание слева подсвечивает читаемый файл и позволяет перейти к любому месту. Обычный вопрос в чате относится ко всему PR. Для фокуса на файле нажми «В чат» рядом с его именем; для фокуса на коде выдели строки. Вложение видно возле ввода, его можно удалить. Все импортированные файлы, их полные патчи, оригиналы бинарных файлов и использованные источники доступны после завершения агента, удаления экспортного каталога и перезапуска сервера; генерация и ответы требуют воркера.

Сохранённые данные и настройки по совместимости находятся в `~/.sherpa`; переменная `SHERPA_DIR` задаёт другой каталог. Перенос проекта и обновление скилла эти данные не удаляют. Сервер слушает localhost. Новая версия появляется только после явного импорта, прежние вопросы и выбранный разбор сохраняются. У старого неполного кэша доступны только ранее сохранённые материалы; недостающие байты требуют явного импорта той же версии.
