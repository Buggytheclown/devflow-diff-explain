# Devflow Diff Explain

Личный инструмент, который проводит по PR от общей архитектуры к отдельным строкам кода: краткое описание проблемы и решения, схема потока данных с окружением изменения, смысловые блоки и упорядоченные файлы с полным диффом. Пояснения внутри файла выделяют важные места; детали можно спросить в чате с привязкой к строкам.

Целевой интерфейс — браузер на компьютере. Старый UI и серверный сценарий ревью удалены: сервер не публикует комментарии и вердикты, не ведёт ревью-отметки и не запускает исправления замечаний. Чтение сохранённых разборов прежних форматов поддерживается отдельно.

## Установка и обновление

Нужны Node ≥ 22.13 и pnpm версии из `package.json`.

```sh
pnpm install --frozen-lockfile
pnpm install:local
```

Установщик собирает приложение и копирует четыре проверенных файла в `~/.agents/skills/devflow-diff-explain`. Симлинки не используются. Предыдущая установка сохраняется вне каталога скиллов; путь резервной копии печатается в конце. Обновление выполняется той же командой после изменения исходников.

Для другого каталога скиллов:

```sh
node scripts/install-local.mjs --target /path/to/skills/devflow-diff-explain
```

## Использование

Вызови скилл в чате агента:

```text
$devflow-diff-explain <ссылка на PR>
```

Поддерживаются Arcanum, GitHub и локальный diff. Для Arcanum нужны авторизация `arc` и доступный checkout соответствующего репозитория; для GitHub — `GITHUB_TOKEN`, `GH_TOKEN` или авторизация `gh`.

Агент открывает локальный UI и строит объяснение. Начни с описания, затем проходи блоки и файлы в предложенном порядке. Для вопроса о коде выдели строки и открой чат. Ранее сохранённый разбор и дифф доступны без подключённого агента; генерация и ответы требуют воркера.

Сохранённые данные и настройки по совместимости находятся в `~/.sherpa`; переменная `SHERPA_DIR` задаёт другой каталог. Перенос проекта и обновление скилла эти данные не удаляют. Сервер слушает localhost.
