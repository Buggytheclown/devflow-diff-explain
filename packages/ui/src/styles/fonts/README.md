# Шрифты Arcanum

YS Text 400/500/700 взят из официальных URL, используемых `data-ui/gravity-themes/lib/fonts/ys-text.scss`:

- https://yastatic.net/s3/home/fonts/ys/4/text-regular.woff2
- https://yastatic.net/s3/home/fonts/ys/4/text-medium.woff2
- https://yastatic.net/s3/home/fonts/ys/4/text-bold.woff2

Liberation Mono скопирован из `data-ui/arcanum/src/ui/styles/liberation-mono.ttf` как fallback к системным моноширинным шрифтам. Файлы поставляются в локальной сборке: при открытии Devflow Diff Explain внешних запросов к шрифтам нет.
